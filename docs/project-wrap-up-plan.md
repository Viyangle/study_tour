# 项目后续收尾计划

**周期：未来 1—2 个月。** 以现有功能为基础，完成前后端联调、推荐效果验证和问题修复，保证系统可稳定演示并完成结项。

**分工：** 本人负责前端所需 API 支持、后端问题修复和接口文档；另一位同学负责推荐算法完善、调参和效果评估。

| 阶段 | API 与后端支持 | 推荐算法 | 阶段成果 |
|---|---|---|---|
| 第 1—2 周 | 梳理前端接口缺口，核对参数、返回值及错误提示 | 固定测试数据，评估现有推荐效果，确定优化重点 | 联调问题清单、算法基线 |
| 第 3—4 周 | 完成核心流程联调，修复权限、状态及异常处理问题 | 调整推荐排序和参数，以相同口径对比效果与响应耗时 | 可完整演示版本、优化对比结果 |
| 第 5—8 周 | 核对部署版本与数据库脚本，完成关键接口回归，更新接口文档 | 固定最终算法版本，整理实验结果与算法说明 | 最终演示、结项材料 |

每周同步一次进度与问题，最后一周冻结功能、集中修复缺陷。若实际周期为一个月，将最后阶段压缩至第 4 周。
