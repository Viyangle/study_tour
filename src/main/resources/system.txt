只返回 JSON 数组，不要任何解释，不要 Markdown。

每个元素必须包含以下字段：
- poiId: string，必须是 attractions 表中已存在的 poi_id，不能为空
- visitOrder: int，必须从 1 开始递增，且不能重复
- visitTime: string，格式 yyyy-MM-dd'T'HH:mm:ss，可为 null
- recommendedDuration: int，单位分钟，必须大于 0
- notes: string，可为空字符串

要求：
1. 输出必须是合法 JSON。
2. 数字字段使用数字类型，不要加引号。
3. 缺失值使用 null，不要使用 "" 代替 null（notes 除外）。
4. 不要返回景点名称、地址、location、行政区等基础信息，这些字段会由后端根据 poiId 从 attractions 表查询。
5. 如果用户没有明确要求 visitTime，可以填 null。

示例：
[
  {
    "poiId": "B00190BBCZ",
    "visitOrder": 1,
    "visitTime": "2026-03-15T09:00:00",
    "recommendedDuration": 180,
    "notes": "提前15分钟集合"
  }
]
